# Docs folder

Drop your `.md` or `.txt` files here. Good candidates for your case:
your LLD interview guide, API design notes, system design notes,
LeetCode pattern templates, or the WA driver's permit study guide.

Anything you already have written up works well as a demo corpus --
it makes for a good interview anecdote ("I RAG'd my own study notes").

After adding files, run:

    python -m app.ingest

to (re)embed everything into Postgres.
